## 使用说明 / Getting started

- **Windows：**下载 EXE 后运行。/ Download and run the EXE.
- **Android：**下载 APK 后，在安卓设备上安装。系统可能要求允许当前下载应用安装此 APK，请自行核实来源后决定。/ Download and install the APK on your Android device. Review any installation permissions requested by your device.
- **macOS：**打开 DMG 并将游戏拖入 Applications；Apple 芯片选 arm64，Intel 选 x64。/ Open the DMG and drag the game into Applications; choose arm64 for Apple silicon or x64 for Intel.
- **Mac 首次打开 / First launch:** 此版使用临时签名、未经过 Apple 公证，首次打开可能需要在系统设置中允许；完整游玩待真实 Mac 验收。/ Ad-hoc signed and not Apple notarized; first launch may require approval in System Settings. Full gameplay on physical Macs remains to be tested.
- 下载请在 Release 的 **Assets** 中选择 `.exe`、`.apk` 或 `.dmg`。GitHub 自动生成的 Source code 压缩包不是游戏。/ Choose the EXE, APK, or DMG under release Assets. The automatically generated Source code archives do not contain the game.
